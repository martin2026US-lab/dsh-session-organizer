# Changelog

All notable changes to this project are documented here.

## 0.1.0 - 2026-09-21

### Added

- Workspace-grouped pinned sessions above the normal workspace list.
- Same-workspace drag ordering and pin/unpin session actions.
- Viewport-aware positioning for the extended session action menu.
- A guarded permanent-delete action for archived sessions.
- Safe handling for the currently open or active target session.
- Deleted-session tombstones and stale-entry recovery to prevent removed sessions from reappearing under Ungrouped.
- English and Simplified Chinese documentation.
